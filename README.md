# LMa – Luxury Aesthetic Clinic Website

A modern and elegant landing page for a luxury aesthetic clinic, designed with a focus on premium visual experience, smooth animations, and responsive design.

## Features

- Modern luxury-inspired UI
- Fully responsive design
- Smooth scrolling and animations
- Elegant typography and layout
- Before & After gallery
- Services section
- Testimonials section
- Contact section
- Mobile-friendly navigation

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

```
/
├── index.html

```

## Preview

This project is intended as a promotional website for a non-surgical cosmetic clinic and can be deployed easily on platforms like Netlify or GitHub Pages.
